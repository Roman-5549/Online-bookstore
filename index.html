Title: Getting started with JavaScript

By: Thomas Theis

Description: The perfect guide to start Javascript development and improve your websites.

New to JavaScript programming ? This book has you covered. With this book, learn how to use one of the most popular programming languages and start creating web applications. Learn the basics of programming: branches, functions, methods, objects, etc... Then learn how to create forms and events, using the document object model (DOM), and learn how to work with big data sets. Create your own interactive web applications using tools such as Ajax, CSS, jQuery and Onsen UI. This book will teach you all of that !

Title: Python with examples

By: NxtGen Publishing

Description: A quick reference guide to get introduced to Python and programming. Ideal for beginners who are just getting started.

Python is one of the most top-notch programming languages written by a language developper It beats any other programming language when it comes to simplicity. This same simplicity allows you to start coding quicker than any other language, and this book will teach you how to do just that. Title: Clean Code

By: Robert C. Martin

Description: A book for more experienced programmers who are looking for a way to improve their coding capabilities by writing cleaner code. A must for future software engineers.

Even bad code can function. But if code isn't clean, it can bring a development organization to its knees. Every year, countless hours and significant resources are lost because of poorly written code. BUt is doesn't have to be that way. In this book designed for more experienced programmers, you will be challenged to reasses your professional values and your commitment to your code. It is a must for any software engineer, developper, or project manager with an interest in producing a better code.

Title: The Linux programming interface

By: Michael Kerrisk

Description: The ultimate guide to learn the linux operating system and it's interface.

The definitive guide to the Linux and UNIX programming interface. The interface employed by nearly every application that runs on a Linux or UNIX system. This book provides detailed descriptions of the system calls and library functions that you will need in order to master the craft of system programming.
